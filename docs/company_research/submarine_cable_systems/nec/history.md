# NEC (해저케이블 사업부) — 역사 / 주요 이벤트

> 1935년 해저 케이블 공장 가동을 시작으로, 동축 중계기 시대와 광케이블 시대를 모두 거치며 지구 11바퀴 분량을 부설한 사업부.

---

## 연혁

| 연도 | 내용 |
|------|------|
| 1899 | NEC Corporation 창업 (해저케이블과 무관한 회사 전체 설립 연도) |
| 1935 | NEC의 해저 케이블 공장(OCC) 가동 시작 |
| 1964 | 해저케이블 부설 사업 개시 (이후 누적 부설 거리 약 45만km, 지구 11바퀴 분량) |
| 1968 | 동축 중계기(coaxial repeater) 생산 개시 — 해저통신 사업 본격화 |
| 1985 | 광섬유·반도체 레이저 상용화로 동축 시스템이 광 중계 방식(optical regenerator)의 광케이블 시스템으로 전환 |
| 2024.01 | 인도 코치(Kochi)-락샤드위프(Lakshadweep) 제도 해저케이블 시스템(약 1,870km) 완공 |
| 2024.12 | Asia Direct Cable(ADC) 완공 — 중국·일본·필리핀·싱가포르·태국·베트남을 연결하는 대용량 해저케이블 시스템 |
