# Advantest (어드반테스트)

> 반도체 테스트 장비(ATE, Automated Test Equipment) 분야의 글로벌 1위 기업. Teradyne과 함께 시장을 양분하며, AI 반도체·HBM 테스트 수요 확대의 직접적 수혜를 받는 "숨은 인프라" 기업.

- **회사명**: Advantest Corporation (株式会社アドバンテスト)
- **티커 / 상장 시장**: 6857 (도쿄증권거래소 프라임시장)
- **설립 / 본사**: 1954년 / 일본 도쿄
- **CEO**: Douglas Lefever (Representative Director, President & CEO, 2024년 4월 취임 — 전임 Yoshiaki Yoshida는 이사회 의장(Chairperson)으로 이동)
- **홈페이지**: https://www.advantest.com
- **섹터 / 산업**: 테크 / 반도체 테스트 장비 (ATE, Automated Test Equipment)
- **시가총액**: 약 $1,399억 달러 (2026년 6월 기준)

---

## 1. 한 줄 요약

Advantest는 반도체가 설계·생산된 후 출하 전 마지막 단계에서 칩이 정상 동작하는지 검사하는
**테스트 장비(ATE)**를 만드는 회사다. Teradyne과 함께 SoC·메모리 테스트 시장을 양분하는
**Big Two** 중 하나이며, 특히 메모리(DRAM, HBM 포함) 테스터 분야에서 강세를 보인다.

---

## 2. 사업 모델 — 어떻게 돈을 버는가

테스트 시스템과 주변기기를 반도체 제조사·OSAT(외주 패키징·테스트 업체)에 판매하며,
소모품·유지보수 서비스에서도 반복 매출이 발생한다.

| 사업 부문 | 설명 | 매출 비중 |
|-----------|------|-----------|
| Semiconductor and Component Test Systems | SoC 테스터, 메모리(DRAM/HBM) 테스터 등 핵심 테스트 시스템 | 핵심 매출원 (구체 비중 확인 필요) |
| Mechatronics | 테스트 핸들러, 디바이스 인터페이스 등 테스트 주변 기계장치 | 확인 필요 |
| Others | 고객 솔루션 지원, 장비 리스 서비스 | 확인 필요 |

---

## 3. 산업 / 시장 내 위치

ATE(반도체 테스트 장비) 시장은 **Advantest와 Teradyne 두 회사가 사실상 양분**하는 듀오폴리 구조다.

- **높은 진입장벽 + 듀오폴리 구조**: 고객(반도체 회사·OSAT)의 신뢰성 검증 사이클이 길어 신규 장비 채택에 오랜 시간이 걸리고, 기존 벤더 전환비용이 매우 높음.
- **AI 반도체 수혜의 "곡괭이" 기업**: HBM, GPU 등 첨단 칩일수록 테스트해야 할 항목과 시간이 늘어나, 특정 칩 회사의 성패와 무관하게 테스트 장비 수요가 함께 증가.
- **메모리 테스트 강세**: HBM을 포함한 메모리 테스터 분야에서 경쟁사 대비 강점을 보유한 것으로 알려짐 (세부 점유율 확인 필요).
