# Advantest (어드반테스트) — 역사 / 주요 이벤트

> 계측기 회사로 출발해 반도체 테스터 국산화 1호를 거쳐, Verigy 인수로 SoC 테스트 시장 1위(점유율 50%+)에 오른 회사.

---

## 연혁

| 연도 | 내용 |
|------|------|
| 1954 | 일본에서 다케다 리켄 공업(Takeda Riken Industry Co., Ltd.)으로 창업, 전자 계측기 사업으로 시작 |
| 1968 | 반도체 테스트 장비 사업 진출 |
| 1972 | 일본 최초로 반도체 테스트 장비 국산화 생산 |
| 1975 | 후지쓰(Fujitsu)가 지분 투자 |
| 1982 | 미국 자회사 설립 |
| 1983 | 도쿄증권거래소 상장 |
| 1985 | 사명을 Advantest Corporation으로 변경 |
| 2000년대 초 | 뉴욕증권거래소(NYSE) 상장 (이후 ADR 형태로 유지되다 상장폐지) |
| 2011 | **Verigy 인수** (약 11억 달러 규모) — SoC 테스트 사업 강화, 이후 ATE 시장 점유율 50% 이상으로 확대 |
| 2020 | Essai Inc. 인수 (테스트 소켓·인터페이스 기술) |
| 2021 | R&D Altanova 인수 (테스트 인터페이스 설계) |
| 2022 | CREA S.r.l. 인수 (전력반도체 테스트 솔루션) |
| 2024.04 | Douglas Lefever CEO 취임, 전임 Yoshiaki Yoshida는 이사회 의장으로 이동 |
