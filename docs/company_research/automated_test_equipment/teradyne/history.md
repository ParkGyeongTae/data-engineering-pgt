# Teradyne (테라다인) — 역사 / 주요 이벤트

> MIT 동문 두 명이 세운 반도체 테스터 회사에서 출발해, LitePoint·Universal Robots 등 인수를 통해 "테스트 + 로보틱스" 이중 사업 구조를 갖추게 된 기업.

---

## 연혁

| 연도 | 내용 |
|------|------|
| 1960 | MIT 동문 Alexander V. d'Arbeloff와 Nicholas DeWolf가 공동 창업 |
| 1961 | 첫 제품(로직 제어 go/no-go 다이오드 테스터)을 Raytheon에 판매 |
| 1966 | 최초의 컴퓨터 제어 칩 테스터 J259 출시 |
| 1987 | 최초의 아날로그 VLSI 테스트 시스템 A500 출시 — 아날로그/디지털 혼합신호 테스트 시장 선도 |
| 2000~2001 | Herco Technologies, Synthane-Taylor 인수 (Teradyne Connection Systems), 이어 회로기판 테스트·검사 기업 GenRad 인수 |
| 2011 | **LitePoint 인수** — 무선(Wireless) 테스트 사업 진출 |
| 2015 | **Universal Robots 인수** — 협동로봇(Cobot) 사업으로 산업 자동화 영역 확장 |
| 2018 | Mobile Industrial Robots(MiR) 인수 — 자율이동로봇(AMR) 사업 추가 |
| 2020 | AutoGuide Mobile Robots 인수 — 로보틱스 포트폴리오 강화 |
| 2026 (2Q) | AI 반도체 수요 급증으로 분기 매출 13.3억 달러 기록(사상 최대), 컴퓨트향 SoC 테스트 매출 전년비 약 600% 성장 |
