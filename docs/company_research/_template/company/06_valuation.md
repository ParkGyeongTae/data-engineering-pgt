## 1. 적용 방법론

**적용 여부 판단 기준** (해당 없으면 체크 해제하고 사유를 반드시 기록):

> 각 방법론의 정의·산식은 [`glossary.md`](../../glossary.md) "1. 밸류에이션 방법론"을 참고. 아래는 이 문서에서 적용 여부를 판단할 때만 추가로 지킬 것.

- [ ] PER 방식 — 적정주가 = EPS × 목표 PER
  - 적자 기업이나 이익 변동성이 극심한 기업엔 부적합.
- [ ] PBR 방식 — 적정주가 = BPS × 목표 PBR
  - **주의**: 최근 대형 M&A(주식교환 방식 대가 지급 등)로 자기자본이 단절적으로 급변한 경우, 과거 평균 배수와 최근 배수가 서로 다른 자본구조를 기준으로 계산돼 평균이 왜곡됨 — 이런 경우 적용하더라도 참고용으로 격하하고 그 이유를 명시.
- [ ] DCF (현금흐름할인법)
  - 실제 성장률이 영구성장률보다 훨씬 높은 고성장 기업엔 **1단계(Gordon growth) 모델**이 구조적으로 지나치게 낮은 값을 낼 수 있음 — 이런 회사는 **고성장기(3~5년) + 영구성장기 2단계 모델**을 쓰거나, 1단계 모델을 쓰더라도 그 한계를 §4에 명시할 것.
- [ ] DDM (배당할인모형)
  - **무배당 기업에는 적용 불가** — 이 경우 체크하지 말고 "무배당으로 해당 없음"이라고 한 줄만 남기고 아래 표에서 관련 행은 통째로 생략(N/A 반복 기입 금지).

**핵심 가정 및 신뢰도**

| 가정 항목 | 값 | 근거 | 신뢰도 |
|-----------|-----|------|--------|
| 목표 PER |  | <동종업계 평균 / 과거 N년 평균 등> | <High/Medium/Low> |
| 목표 PBR |  | <동종업계 평균 / 과거 N년 평균 등> | <High/Medium/Low> |
| 할인율 (WACC, DCF) |  |  | <High/Medium/Low> |
| 영구/장기 성장률 (DCF) |  |  | <High/Medium/Low> |
| 배당성장률 (DDM) |  |  | <High/Medium/Low> |
| 요구수익률 (DDM) |  |  | <High/Medium/Low> |
| **방법론별 가중치 (종합 시)** | <예: PER 50% / DCF 30% / PBR 20%> | 신뢰도가 Low인 방법론은 가중치를 낮추거나 제외 — **균등가중을 기본값으로 쓰지 말고, 왜 이 가중치인지 반드시 서술** | — |

> 신뢰도가 Low인 방법론이 하나라도 있으면, 아래 §2·§3의 "종합 적정주가"는 그 방법론을 제외했을 때 값도 괄호로 함께 표기해 평균이 이상치에 얼마나 좌우되는지 드러낼 것.
