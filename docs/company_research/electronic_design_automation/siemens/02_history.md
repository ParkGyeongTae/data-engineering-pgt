# Siemens AG (지멘스) — 역사 / 주요 이벤트

> 1847년 전신(telegraph) 회사로 출발해 170년 넘게 이어온 독일 대표 산업 기술 기업. 최근에는 헬스케어·에너지 사업을 별도 상장시키고, 소프트웨어(자동화, EDA)로 무게 중심을 옮기는 중.

> ⚠️ 모든 항목은 웹검색으로 확인한 사실만 기록. 추측이나 출처 불명 내용은 작성 금지 — 가능하면 연도뿐 아니라 월까지(예: 2021.02) 표기하고 출처를 함께 남길 것.

---

## 연혁

| 연도 | 내용 |
|------|------|
| 1847 | Werner von Siemens와 Johann Georg Halske가 베를린에서 Telegraphen-Bauanstalt von Siemens & Halske 창업. 전신(telegraph) 기술 사업으로 출발 |
| 1848~1853 | 유럽 최초의 장거리 전신선(베를린~프랑크푸르트) 구축, 러시아 국영 전신망(약 9,000km) 수주 등으로 사업 확장 |
| 1966 | Siemens & Halske, Siemens-Schuckertwerke, Siemens-Reiniger-Werke 3개 법인이 통합되어 현재의 Siemens AG 출범 |
| 2017.03 | **Mentor Graphics 인수 완료** (약 45억 달러) — 반도체 EDA 시장 진입. Mentor Graphics는 이후 Siemens EDA로 브랜드 통합 |
| 2018.03 | 헬스케어 사업부를 **Siemens Healthineers**로 분할, IPO를 통해 별도 상장 (Siemens는 다수 지분 유지) |
| 2020.09 | 에너지 사업부를 **Siemens Energy**로 스핀오프, 별도 상장 |
| 2021.02 | Roland Busch가 Joe Kaeser의 뒤를 이어 President 겸 CEO로 취임 |
